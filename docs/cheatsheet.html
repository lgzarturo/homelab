github.com/lgzarturo/homelab

1 · Antes de empezar

DockerDocker Desktop (Windows, macOS) o Docker Engine (Linux), encendido.
GitPara bajar el código.
Go 1.26+Para compilar el binario. En Windows: winget install GoLang.Go
Memoria16 GB recomendados. Con 8 GB deja solo ollama,openwebui en COMPOSE_PROFILES.
InternetSolo la primera vez, para descargar imágenes y modelos (varios GB).

2 · Bajar, compilar y levantar

  1. Baja el código y entra a la carpeta: 
    git clone https://github.com/lgzarturo/homelab.git
cd homelab
  2. Compila el binario: 
    go build -o homelab.exe .   # Windows
go build -o homelab .       # macOS y Linux
  3. Levanta todo: crea .env, arranca los servicios y descarga los modelos. 
    .\homelab.exe up            # Windows (PowerShell)
./homelab up                # macOS y Linux
  4. Comprueba que todo quedó bien: 
    .\homelab.exe doctor
.\homelab.exe status
  5. Conversa: 
    .\homelab.exe chat

En el resto de la guía, homelab significa .\homelab.exe en Windows y ./homelab en macOS y Linux, ejecutado dentro de la carpeta del proyecto.

4 · Una sola pregunta (ask)

homelab ask "¿Cómo están el disco y la memoria?"
homelab ask --nota "Informe" "Resume el estado del equipo"
docker compose logs n8n | homelab ask "¿Hay errores?"

Escribe solo la respuesta y termina con código 1 si falla: sirve en scripts, tareas programadas y n8n.

5 · El chat

homelab chat                     # modelo por defecto
homelab chat gemma4:e2b-it-qat   # otro modelo
homelab chat --pensar            # con razonamiento
Dentro del chatQué hace
/ayudaMuestra estos comandos
/modelo <nombre>Cambia de modelo sin salir
/modelosLista los modelos instalados
/pensarActiva o desactiva el razonamiento
/limpiarOlvida la conversación
/salirTermina (también Ctrl+D)
Ctrl+CCorta la respuesta sin cerrar el chat

Tras cada respuesta aparece: espera hasta la 1ª palabra · velocidad de lectura y de escritura (tokens/s) · tokens · tiempo total. El chat recuerda los últimos 6 mensajes.

6 · Qué preguntarle

  • ¿Cuánta RAM tengo libre? ¿Queda espacio en el disco?
  • ¿Cuánto lleva encendido el equipo?
  • ¿Está funcionando n8n? ¿Qué servicios están detenidos?
  • ¿Qué dicen los últimos registros de open-webui?
  • ¿Qué programas usan más memoria?
  • Guarda una nota titulada «Pendientes» con estos tres puntos…
  • ¿Qué expresión de cron corre algo cada lunes a las 6?
Con 2 hilos, el modelo por defecto tarda de 20 a 60 s por respuesta. Es normal: la espera hasta la primera palabra es de 14 a 22 s.

8 · Comandos

ComandoQué hace
homelab upLevanta los servicios y descarga lo que falte. Repítelo tras editar .env. --sin-modelos no descarga modelos; --lab deja solo Ollama.
homelab downDetiene los servicios. Los datos se conservan.
homelab statusEstado de cada servicio, versión de Ollama, modelo en memoria y direcciones.
homelab doctorRevisa Docker, memoria, permisos de la carpeta, puertos ocupados y modelos que no caben.
homelab logs [servicio] [-f]Registros de los servicios. Ejemplo: homelab logs ollama -f
homelab modelsModelos instalados: tamaño, parámetros, cuantización y capacidades.
homelab pull <modelo>...Descarga modelos de Ollama o de Hugging Face (hf.co/usuario/repo:cuantización). No empieza si el modelo no cabe; --forzar lo salta.
homelab rm <modelo>...Borra modelos instalados.
homelab chat [modelo]Conversa con el agente. --pensar activa el razonamiento.
homelab ask "pregunta"Una sola respuesta, sin chat. --modelo, --pensar, --nota "título". Sin pregunta, la lee de la entrada estándar.
homelab bench [modelos...]Mide y compara modelos. --runs, --suite, --hilos, --ctx, --pensar.
homelab bench compareCruza los informes guardados en resultados/.
homelab version · helpVersión y ayuda. Opción global --dir <ruta> (o HOMELAB_DIR) para usar otra carpeta.

10 · Medir modelos (bench)

homelab bench                 # todos, 3 rondas
homelab bench --suite mantenimiento
homelab bench gemma4:e2b-it-qat --runs 1
homelab bench --hilos 2,4,8   # compara hilos
homelab up --lab              # solo Ollama, para medir
homelab up                    # levanta todo otra vez

Informes en resultados/. Suites propias: JSON en pruebas/.

12 · Si algo falla

Docker no respondeAbre Docker Desktop y espera a que arranque.
No deja escribirWindows: permite homelab.exe en Seguridad.
Ollama no respondehomelab status y homelab logs ollama
Modelo no instaladohomelab pull <modelo>
El modelo no cabeSube OLLAMA_MEM o usa uno más pequeño.
Puerto ocupadohomelab doctor dice cuál.
Va muy lentoSube OLLAMA_CPUS o usa gemma4:e2b-it-qat.
